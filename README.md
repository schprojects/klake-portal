# Klake Lake Portal

A free, static website for the Klake Lake rejuvenation and maintenance initiative.

Built with **Hugo** + **GitHub Pages** + **Google Drive**.

## Quick Links

- **Live site:** https://your-org.github.io/klake-portal/
- **Report:** [REPORT.md](./REPORT.md) — complete implementation guide
- **Maintenance:** [MAINTENANCE.md](./MAINTENANCE.md) — quick reference for non-tech users

## Project Structure

```
content/        ← All text content (markdown)
static/         ← Thumbnails, CSS, small PDFs
layouts/        ← HTML templates (tech folks only)
.github/        ← GitHub Actions (auto-deploy)
```

## Tech Stack

| Tool | Purpose |
|------|---------|
| Hugo | Static site generator |
| GitHub Pages | Free hosting |
| Google Drive | Master copies of photos & PDFs |
| GitHub Actions | Auto-build and deploy |
